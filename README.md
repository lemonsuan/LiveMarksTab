# 📑 LiveMarksTab — Chrome 新标签页书签导航

> 自定义 Chrome 新标签页，将浏览器书签自动渲染为可视化导航界面，支持双向实时同步。

---

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| **新标签页接管** | 每次 `Cmd/Ctrl+T` 自动展示自定义导航页 |
| **三种布局** | 分行（默认）/ 卡片网格 / 侧边栏，可在设置中切换 |
| **书签自动渲染** | 读取 Chrome 全量书签，一级文件夹 → 分类区块，嵌套文件夹可折叠 |
| **双向同步** | 导航页修改 ↔ Chrome 书签库实时同步，带 Sync Lock 防死循环 |
| **拖拽排序** | 拖拽文件夹和书签调整顺序，同步回 Chrome 书签 |
| **深浅模式** | 浅色 / 深色前景切换，联动背景色，用户自定义背景优先 |
| **配色方案** | 5 套预设配色（靛蓝 / 翠绿 / 琥珀 / 玫瑰 / 紫罗兰） |
| **自定义背景** | 内置渐变 / 网络图片 URL / 本地上传 |
| **悬浮工具栏** | 深浅切换 / 密码管理 / 浏览历史 / 扩展管理 / 设置 |
| **搜索** | 输入关键词实时过滤书签，回车跳转搜索引擎 |
| **多引擎切换** | Google / Bing / 百度 / DuckDuckGo / GitHub |
| **右键菜单** | 打开 / 新标签页打开 / 编辑 / 删除 |

## 📂 项目结构

```
LiveMarksTab/
│
├── manifest.json            # Chrome 扩展清单 (Manifest V3)
├── newtab.html              # 新标签页主页面
│
├── css/
│   └── style.css            # 全局样式 (CSS 变量 + 主题 + 布局)
│
├── js/
│   ├── app.js               # 入口 (初始化顺序)
│   ├── theme.js             # 主题管理 (深浅/配色/背景)
│   ├── bookmarks.js         # 书签读取 + 三种布局渲染 + 拖拽排序
│   ├── search.js            # 搜索栏 + 多引擎切换
│   ├── sync.js              # 双向同步 + Sync Lock
│   ├── settings.js          # 设置面板 + 持久化
│   └── utils.js             # 工具函数
│
└── icons/                   # 扩展图标
```

## 🚀 安装与使用

1. 打开 Chrome → `chrome://extensions/`
2. 开启 **开发者模式**
3. 点击 **加载已解压的扩展程序** → 选择项目目录
4. 打开新标签页 (`Cmd+T`) → 看到自定义导航页

更新：修改代码后在扩展页面点击 🔄 刷新按钮即可。

| 权限 | 用途 |
|------|------|
| `bookmarks` | 读写 Chrome 书签数据 |
| `favicon` | 获取网站图标 |
| `storage` | 存储用户偏好设置 |

---

## 🛠️ 开发约定

- **纯原生 JS**，无框架依赖，确保极致秒开
- **脚本加载顺序**: `utils → theme → search → bookmarks → sync → settings → app`
- **CSS 变量统一管理**: 修改主题色请编辑 `:root` 中的变量
- **命名规范**: 函数 `camelCase`，CSS 类 `kebab-case`，DOM ID `kebab-case`
