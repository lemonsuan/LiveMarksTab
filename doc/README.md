## 项目当前状态

- **版本**：1.0.0
- **技术栈**：Chrome Extension Manifest V3 / 纯 HTML + CSS + JS
- **仓库**：https://github.com/lemonsuan/LiveMarksTab

## 功能概览

| 功能 | 说明 |
|------|------|
| 书签渲染 | 行布局 / 卡片瀑布流，子文件夹网格卡片展开 |
| 实时搜索 | 输入即过滤，支持标题和 URL |
| 多引擎搜索 | Enter 单引擎 / Shift+Enter 多引擎同时打开 |
| 拖拽排序 | 文件夹区块和书签项均可拖拽，同步到 Chrome |
| 右键菜单 | 打开、编辑、删除、生成二维码 |
| 二维码生成 | 基于 qrcode-generator 库，支持复制图片/URL |
| 书签清理 | 扫描所有 URL 可访问性，筛选+批量删除失效书签 |
| 深浅主题 | 一键切换，联动默认背景色，用户自定义背景优先 |
| 悬浮工具栏 | 深浅切换 / 密码管理 / 历史 / 扩展 / 书签清理 / 设置 |
| 设置面板 | 侧栏 Tab 布局，支持重置所有设置 |
